# Trunk patches

This directory records fork-specific changes that live in trunk source rather than behind an extension seam: each entry names the files touched, the behaviour change, and why the hook cannot be expressed through a supported extension point. Everything listed here is a rebase liability, so keep entries terse and current.

**Lifecycle rule:** every section here MUST collapse once upstream exposes an equivalent seam or the fork-side implementation moves out of core — delete the section in the same change that lands the replacement.

## packages/coding-agent/src/modes/rpc/ — managed RPC full negotiation (issue #9)

- Slice: [mouriya-s-lab#9](https://github.com/mouriya-s-lab/oh-my-pi/issues/9), extending the existing `RpcReadyFrame.nativeAgent`, `RpcInputDispatcher.managed`, and `expectManagedBootstrap` surfaces. Changes live in `rpc-types.ts`, `rpc-frame.ts`, `rpc-mode.ts`, `rpc-client.ts`, and new `lease.ts`; the existing endpoint contract/fake, opt-in managed local adapter, and per-command session/bash cancellation seams are extended rather than replaced.
- Capability negotiation: native-agent major 1 requires all 14 numeric flags. `sessionControl`, `peerRoster`, `replyQuiescence`, `outputContract`, `workpoolBinding`, `heartbeat`, `lease`, `resumeOwnership`, and `errorTaxonomy` are `1`; [#11](https://github.com/mouriya-s-lab/oh-my-pi/issues/11) enables `ircBidirectional: 1`. `resultResource`, `interactionUi`, `isolatedWorkspace`, and `hostCallbacks` remain `0`. Missing/old declarations stop bootstrap before any command is written; application version is advisory, not a compatibility gate.
- Request/response envelopes carry optional `correlationId`, `scope`, `generation`, and `operationId`. Managed clients mint UUID correlation IDs and prefer them over `id`; servers echo received identifiers without fabrication. The IRC transport below binds generation and canonical sender authority at prepare; generation on unrelated control requests remains correlation metadata.
- Managed failures carry both `message` and one of eight `RpcErrorCode` values: `authorization-denied`, `config-missing`, `protocol-incompatible`, `remote-execution-failed`, `user-cancelled`, `timeout`, `connection-lost`, or `resource-unavailable`. Legacy response/error bytes remain unchanged.
- `get_state`, `abort`, `abort_bash`, `heartbeat`, `cancel_run`, `terminate`, `park`, and `resume` use the managed control path without waiting on the serial task queue. Existing host/UI side channels remain available without advertising the deferred native-agent bridges.
- Four lifecycle paths remain distinct: targeted `cancel_run` waits for endpoint terminal/reply-drained facts and reports `cancelled` or bounded `cleanup-unconfirmed`; `terminate` acknowledges only after cleanup and flushes before exit; external/lease-triggered `park` uses the endpoint ownership gate and returns an opaque reference only for released work; unexpected EOF cancels every owned in-flight run before draining. Per-command bash signals keep cancelling one run from cancelling another; whole-session legacy abort still cancels all shells.
- Heartbeat defaults are 10 s and receive-side lease defaults are 30 s, confirmed by `prepare` using the smaller proposal. Both peers send heartbeats; valid received controls renew `lastHeartbeatAt`, never outgoing pings. Expiry reports `connection-lost`/`execution-unknown`, cancels owned work, parks released runs and closes after cleanup, without replay.
- Test-only timing escape hatches: `PI_MANAGED_LEASE_SECONDS=2 PI_MANAGED_HEARTBEAT_SECONDS=1` compress row 5's real local subprocess lease wait to 3.1 s. These environment overrides are read when constructing the lease, never override confirmed explicit values, and are not production timing recommendations. A separate negotiation assertion verifies the 10 s / 30 s defaults.
- Resume resolves the original in-memory session/reference and expected run ID through `ensureLive`; active or cleanup-pending ownership returns `still-owned`, and an unknown reference is unavailable rather than creating a session. In-memory release/park/resume is exercised here; a reference is not durable across process exit.
- Frame negotiation independently takes the minimum of `maxFrameBytes`, `maxReassembledFrameBytes`, and `maxResourceChunkBytes` (resource default 256 KiB). The next `negotiate_protocol` response activates the limits; already-encoded iterables retain their original chunk layout. Managed overflow errors retain correlation and taxonomy.
- Runtime evidence: real local in-repo `bun cli.ts --mode rpc --rpc-subagent` processes execute RPC bash sleeps. Controls cancel a 5 s run while a companion completes; plain EOF preserves `finished`/`cancelled:false` while managed EOF suppresses `finished`/reports `cancelled:true`; a compressed lease cancels both active runs before drain and the real client observes `execution-unknown`. No SSH or model API request is used.
- **blocked pending** [#13](https://github.com/mouriya-s-lab/oh-my-pi/issues/13): `resultResource=1`, `interactionUi=1`, remote isolated-workspace/resource/UI bindings and host-tool bridge. **blocked pending** [#14](https://github.com/mouriya-s-lab/oh-my-pi/issues/14): real dual-remote heartbeat blocking, cross-version compatibility matrix and durable references.
