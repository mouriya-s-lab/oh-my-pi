# 计量

负责按归属单位取回一份用量读数，并如实标明这份读数是完整的还是只含采样那一刻活着的进程；不负责阈值、去重与告警，也不负责保留历史。

## 为什么

计量单独成为子模块：它只用到登记模块的"单位名下有哪些进程、单位自己开了什么围栏"和平台的读数连接，登记模块不需要知道读数怎样取回、怎样相加。

读数以归属单位为单位，不以单个进程为单位：十个各占一份的进程合起来才是一次工具调用的真实开销，按单个进程比较阈值永远看不到总量。

读数带 ``Metering`Coverage``：围栏能力为 `aggregate` 时读数含已退出成员，否则只含活着的进程。不把两种读数混成一个数：只含活着的读数在进程退出后会回落，消费方要知道这一点才能正确比较。

## 语义

``Metering`Sample`` 取回的是那一刻的副本；两次采样之间的间隔由消费方决定。只含活着的读数里，两次采样之间出生又退出的进程不出现。

``Metering`Ledger`` 只保留每个单位最近一次读数；历史与峰值由消费方按自己的需要保留。
